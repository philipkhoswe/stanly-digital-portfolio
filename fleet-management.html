Vehicle & Fleet
Management System

A Python-based application designed to support vehicle records management, driver administration, trip monitoring, fuel reporting and maintenance alerts.

Python Project · Version 2.1

Project Overview

The Vehicle & Fleet Management System is a menu-driven Python application that uses CSV files to store and manage fleet information. It brings together vehicle records, driver details, trip activities and operational reports in one application.

The project demonstrates practical programming, structured data handling, validation and backup management.

Application Dashboard

The screenshot below shows the running Vehicle & Fleet Management System dashboard.

Key Features

Vehicle Management

Register, view, edit and delete vehicle records.

Driver Management

Maintain driver information and licence records.

Trip Management

Record, edit, delete and review trip activities.

Maintenance Alerts

Monitor scheduled vehicle services and driver licence expiry dates.

Monthly Reports

Review monthly trip activity, fuel consumption and fuel costs.

Data Backup

Create CSV backups and access the backup restoration function.

Technologies Used

Python CSV File Handling Functions Data Validation Pydroid 3

Project Testing

The application has undergone functional testing covering startup, data initialization, vehicle registration, vehicle editing and deletion, driver registration, trip management, reports and CSV backup creation.

Further testing of backup restoration and remaining edge cases is ongoing.
